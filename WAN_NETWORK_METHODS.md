# WAN-aware network method gates

Objective: 10× covered all-party bodies on matched fresh-response and conversation
cohorts, with prompt/activation privacy and low client CPU/memory. Incremental
measured improvements enter the existing SDK when their complete execution and
resource contracts pass. These are new PLLM engineering hypotheses, not claims
of literature novelty.

Every party defaults to 100 Mbps down and 40 Mbps up (decimal megabits/second).
Its concurrent peers share those limits. Analytic bandwidth floors, loopback
timings and actual shaped-network measurements are separately labeled.
`benchmark run --wan` now enforces these shared rates with Docker-backed party
queues and reports measured end-to-end/online/decode tokens per second.
`--wan-estimate` retains analytical-only operation. A bounded pinned Qwen cohort
and reproduction commands live in `docs/evidence/wan-emulation-2026-10-04.md`.

| Hypothesis | Experiment and rejection gate |
| --- | --- |
| Project before resharing | Three party-local degree-two products project through a public matrix before degree reduction. Check exact field algebra, non-colluding views and all directed re-sharing bodies; price decoder-wide numerics separately. |
| Coupled prepared residue coding | Use public per-output integer bounds to encode both corrections and online outputs in smaller exact residue rings. Check masks, signed reconstruction and every decoder logit/KV; include client codec CPU and metadata. |
| Bit-plane public artifact delivery | Reversible blocked bit-plane transform before bounded compression. Check exact source hashes, frame admission, source mutation and decoder parity; measure cold bytes and client decode CPU. |
| Fixed-batch private row retrieval | Evaluate independent DPF queries during one table traversal with a public batch size. Keep positions/counts hidden; check exact bytes, replay and atomic malformed-batch handling. Count keys/replies and provider expansion CPU. |
| Public orthogonal activation spreading | Block-Hadamard transforms on public weights and client activations preserve the float32 linear function before quantization. Compare lower precision against held-out fixed-checkpoint prefill/decode; count client transforms and exact wire widths. |

Resident methods must cover attention, normalization, rescaling and feedback
before promotion. A component saving does not establish a decoder saving. Public
artifact compression never applies to private masked payloads. An observed head
candidate count is not a public capacity certificate. No production privacy
claim follows from co-located research roles.
