# Reproduction recipes

Each `Rxx.json` filename uses a discovery alias from `../methods/registry.json`; it is not a source,
artifact, or method identity. `source_acquisition_status` records acquisition independently from
`workflow_status`. Unset commands and locks remain blockers. Required evidence names are
deliverables, not current evidence.

Recipe gates are acquisition, specification, independent reference, native implementation,
assurance, matched benchmark, and documentation. Failure is recorded; no plaintext fallback or
invented result is allowed.
