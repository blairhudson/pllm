    • Parameters: Parties agree on input size n and output size m.
    • Input:
        – G inputs a function f : {0, 1}n → {0, 1}m .
        – Parties input a shared function input JaK where a ∈ {0, 1}n .
    • Output: Parties output a sharing Jf (a)K.
    • Communication : G sends to E (2n − 1)κ + nmκ + 2n m bits.
    • Computation: Parties use O(2n cκ + 2n mκ + nmcκ + 2n mcκ /κ) computation.

    • Procedure:
        – Let ⟨⟨A, A ⊕ a∆⟩⟩ = JaK.
        – G computes α ≜ lsb(A). Let x = a ⊕ α. E computes:

                                        lsb(A ⊕ a∆) = lsb(A) ⊕ a · lsb(∆) = α ⊕ a = x

        – G injects ⟨⟨α∆, 0⟩⟩ = JαK as input. Parties compute JxK = JaK ⊕ JαK.
        – Parties use one-hot garbling (Figure 1) to compute JH(x)K.
        – Parties use Figure 5 to compute Jr(x)K where r : {0, 1}n → {0, 1}m is a uniformly random
          function. As a side-effect, G now holds r.
        – Let f ′ be a function that computes the following:

                                                  f ′ (x) ≜ f (x ⊕ α) ⊕ r(x)

        – G computes the truth table T (f ′ ) for f ′ and sends T (f ′ ) to E.
        – Parties compute and output:
