Verification. To verify the output of delegated embedding, we use hashing.
The model owner publishes a (second preimage-resistant) hash of each entry in
the table T . To verify a claimed result y, a client can simply hash y and compare
it with the corresponding hash value. If we instantiate the hash function with
SHA256 and take V = 128000, the size of the verification information stored
by the client is 4MB; verification requires only one hash evaluation. We provide
a formal description of these procedures in Figure 4.
