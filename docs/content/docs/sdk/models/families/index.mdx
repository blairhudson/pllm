`pllm.lower_model(config, batch=..., max_input_tokens=..., max_new_tokens=...)`
turns model configuration and workload limits into a `ModelPlan`. It does not
download weights or tokenizers, choose a device, or start a runtime.

Current source readers validate exact upstream configuration contracts and
produce the same model-neutral plan format. The plan records operators, layers,
weight references, persistent state, workload limits, and source identity.
The [architecture compatibility matrix](/sdk/reference/status/#decoder-architecture-compatibility)
breaks each source configuration into reusable semantic, numeric, state, and
import requirements with explicit runtime blockers. When a model needs a new
piece, PLLM extends that shared contract instead of implementing a family-named
compiler method. Even a feature used by one checkpoint receives a reusable
operator contract. Future source-schema differences should prefer declarative
mapping into those contracts, not one-off execution adapters.

| Adapter | Validated configuration scope | Added semantics |
| --- | --- | --- |
| `pllm.qwen2.v1` | dense Qwen2 configuration contract | grouped-query attention, rotary position, gated SiLU MLP, KV state |
| `pllm.qwen3.v1` | dense Qwen3; pinned mini-coder-4b fixture | explicit head width, Q/K normalization, bias-free attention |
| `pllm.dense_gated_decoder.v1` | bounded bias-free dense Llama-style source; default and `llama3` wavelength-transition rotary | reuses grouped-query attention, rotary position, SiLU MLP, KV state, tied or untied head |
| `pllm.qwen3_5_text.v1` | pinned Qwen3.5-4B text decoder | hybrid full attention and gated-delta recurrence, convolution and recurrent state |
| `pllm.phi4_mini.v1` | pinned Phi-4-mini-instruct decoder | fused QKV, fused gate/up, partial LongRoPE |
| `pllm.gemma4_e2b_text.v1` | pinned Gemma 4 E2B text decoder | hybrid attention, shared KV suffix, double-wide suffix MLP |
| `pllm.gemma4_e4b_text.v1` | pinned Gemma 4 E4B text decoder | hybrid attention, shared KV suffix, PLE, softcap |

Describing a model is not the same as loading its checkpoint or running it
privately. Compiler support, output quality, benchmarks, and deployment are also
separate. Check [current support](/sdk/reference/status/) before choosing a model.

Start with a [source kind](/sdk/models/sources/) and choose a family: Qwen2
supports the pinned public-weight checkpoint path and a tiny test model;
dense Qwen3 has pinned compiled-checkpoint functionality; the bounded Llama-style
source passes tiny default and bounded Llama 3 wavelength-transition checkpoint
tests, including full prefill/decode against a float32 reference and client-only
and prepared gateway runs. A [pinned public Llama 3.1 8B configuration mirror](https://huggingface.co/unsloth/Meta-Llama-3.1-8B-Instruct/blob/a2856192dd7c25b842431f39c179a6c2c2f627d1/config.json)
also lowers and compiles for a bounded 8+2-token workload without loading weights.
Other scaling modes and real Llama checkpoint quality
remain unvalidated. Qwen3.5 has semantic plan coverage only; Phi-4-mini
compiles in its original-context regime and passes a generated tiny checkpoint
through fused-weight binding, PyTorch reference parity, and prepared/client-only
gateway requests. Its real checkpoint and extended-context cache transition
remain unvalidated.
Gemma 4 E2B/E4B both have complete baseline schedules; pinned E2B additionally
executes locally and through a prepared in-process HTTP request, while E4B has
no checkpoint execution. A supported importer and runtime binding must still
be verified separately. The
[model workflow](/sdk/models/) shows a complete Qwen2.5 experiment.

## Python SDK example

```python
from pllm import Deployment, ExecutionBudget, Experiment, Model
from pllm.profiles import MaskedLinearCpu

experiment = Experiment(
    name="family-guide",
    pipeline=MaskedLinearCpu(Model.hf("Qwen/Qwen2.5-0.5B-Instruct")),
    deployment=Deployment.local(root="local://family-guide"),
    budget=ExecutionBudget(requests=1, max_input_tokens=64, max_new_tokens=8),
)
assert experiment.resolve().requires_preparation
```

API: [Python SDK objects and signatures](/sdk/reference/python/pllm/#objects-and-signatures)

Save as `experiment.py`; install optional `he` via
[Installation](/learn/installation/) and run
`pllm gateway --local --experiment experiment.py:experiment --trust-python`.
The pinned Qwen2 path is runnable. Pinned Gemma E2B has its separately scoped
local-clear and prepared loopback diagnostics; Qwen3.5, Phi and E4B remain
plan-only or incomplete at the checkpoint-execution boundary.
