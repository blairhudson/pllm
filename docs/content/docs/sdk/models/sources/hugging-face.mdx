title: "Hugging Face source"
description: "Pin a public checkpoint repository while preserving the separate import step."
---

[`Model.hf`](/sdk/reference/python/pllm/#objects-and-signatures) declares a
repository, optional revision, and local-files-only policy. `load_model`
resolves its actual source files, validates an importer, and records a
path-independent checkpoint lock. For a supported Qwen2.5-0.5B-Instruct
checkpoint, a public masked-linear experiment can run locally; generic HF
repository names do not imply compatible tensor shapes or compiler coverage.
The base package constructs and inspects the source without downloading it.
Remote pulls use Hugging Face's shared snapshot cache (`HF_HUB_CACHE`, or the
standard `~/.cache/huggingface/hub`), including when `local_files_only=True`.
`--hf-cache-dir` selects that same cache root, rather than a second PLLM model
store. A pinned revision and the actual source-file hashes enter the checkpoint
lock. Streamed integer compilation uses a separate regenerable cache at
`~/.cache/pllm/compiled`: its default 6 GiB limit prunes least-recently-used
completed stages after loading, keeping active stages until unload. Set
`PLLM_COMPILED_CACHE_MAX_BYTES` to a positive byte count to change that limit.

## Python SDK example

```python
from pllm import Deployment, ExecutionBudget, Experiment, Model
from pllm.profiles import MaskedLinearCpu

experiment = Experiment(
    name="hf-source-guide",
    pipeline=MaskedLinearCpu(Model.hf("Qwen/Qwen2.5-0.5B-Instruct")),
    deployment=Deployment.local(root="local://hf-source-guide"),
    budget=ExecutionBudget(requests=1, max_input_tokens=64, max_new_tokens=8),
)
assert experiment.pipeline.model.kind == "huggingface"
assert experiment.resolve().requires_preparation
```

Save as `experiment.py`; install optional `he` from
[Installation](/learn/installation/) and run
`pllm gateway --local --experiment experiment.py:experiment --trust-python`.
The model is resolved when serving, not during construction.
