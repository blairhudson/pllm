Block-scale numeric and packed-weight import with exact artifact binding.

This variant needs a complete model-neutral IR/numeric contract.

## Checked decoder configurations

No checked source adapter currently requires this capability.

## Candidate families

- [DeepSeek-V3 family](https://huggingface.co/deepseek-ai/DeepSeek-V3/blob/main/config.json): required executable variant missing. Multi-head latent attention, routed/shared experts, YaRN, FP8 import and complete protected/quality coverage.

## Selection and next gate

The following **importable, non-executable** classes reserve missing reusable contracts. They are excluded from component discovery, Experiment selection, search and provider registration:

- [`pllm.quantization.Fp8BlockScaleImport`](/sdk/reference/python/pllm/quantization/#fp8blockscaleimport) (`pllm/planned-model-capability/fp8-import/v1`): Validate FP8 packed checkpoint artifacts, block scales, and executable numeric conversion..

## Python SDK example

    raise AssertionError("missing capability must remain unavailable")
