Numeric and packed-weight import with exact artifact binding.

This variant needs a complete model-neutral IR/numeric contract.

## Checked source adapters

No checked source adapter currently requires this capability.

## Candidate families

- [gpt-oss 20B](https://huggingface.co/openai/gpt-oss-20b/blob/main/config.json): required executable variant missing. Alternating sliding/full attention, MoE routing, YaRN, MXFP4 weight representation and checkpoint binding.

## Selection and next gate

The following **importable, non-executable** classes reserve missing reusable contracts. They are excluded from component discovery, Experiment selection, search and provider registration:

- [`pllm.quantization.Mxfp4CheckpointImport`](/sdk/reference/python/pllm/quantization/#mxfp4checkpointimport) (`pllm/planned-model-capability/mxfp4-import/v1`): Validate MXFP4 packed checkpoint blocks, scales, and their executable numeric conversion..

## Python SDK example

```python
from pllm.quantization import Mxfp4CheckpointImport
from pllm.components import ModelCapabilityUnavailable

try:
    Mxfp4CheckpointImport()
except ModelCapabilityUnavailable as exc:
    assert exc.identity == "pllm/planned-model-capability/mxfp4-import/v1"
else:
    raise AssertionError("missing capability must remain unavailable")
```
