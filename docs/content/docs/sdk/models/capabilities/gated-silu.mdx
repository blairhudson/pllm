## Checked source adapters

- [Dense Qwen2 (Qwen2.5-0.5B-Instruct)](/sdk/models/families/qwen2/): part of its bounded complete baseline schedule. Pinned Qwen2.5-0.5B local prefill/decode functionality test; tiny compiled two-role protocol test. The historical baseline cohort predates compiler-bound live execution **Next:** Other Qwen2 checkpoints need their own import, configuration, and quality checks; protected whole decoder absent.
- [Dense Qwen3 (Qwen3-0.6B)](/sdk/models/families/qwen3/): part of its bounded complete baseline schedule. Pinned Qwen3-0.6B checkpoint imported and executed through 114 compiled baseline stages, prefill and decode; tiny compiled two-role protocol test and scoped clear-reference probes, no real-checkpoint provider benchmark **Next:** W4A4 fails top-token parity on two checked prompts; the local-role default W8A8 also fails one short prompt. Quantization-quality, real-checkpoint serving and matched benchmark evidence, and protected whole-decoder execution remain open.
- [Bounded dense bias-free decoder (tiny Llama-style fixtures)](/sdk/models/families/): part of its bounded complete baseline schedule. A pinned public Llama 3.1 8B configuration mirror lowers and compiles for a bounded 8+2 token workload without loading weights. Generated tiny bias-free checkpoints pass unscaled tied/untied parity and bounded wavelength-transition scaling: scaled W8A8 prefill/decode matches PyTorch selections with less than 0.05 worst logit error; prepared and client-only SDK/gateway requests complete **Next:** No real Llama checkpoint, tokenizer or representative quality evidence; other RoPE scaling types, sliding attention, projection bias and protected execution remain unsupported.
- [Qwen3.5-4B text decoder](/sdk/models/families/qwen3-5/): part of its bounded complete baseline schedule. Pinned Qwen3.5-4B text configuration lowers to a complete native baseline schedule. A generated tiny checkpoint binds fused projection, convolution and decay artifacts and runs the client-only compiled prefill/decode decoder; selected tokens match the upstream float32 Torch reference and W8A8 logit drift stays below 0.05. A second generated-tiny test completes prepared SDK and gateway requests with two local children, masked stage traffic and zero plaintext prompt/token-ID bytes sent. The text-only partial MRoPE numeric profile independently matches Torch at checked positions **Next:** Official Qwen3.5 checkpoint import and independent reference quality, real-checkpoint provider serving, protected execution, independent providers and independent multimodal position axes remain unchecked.
- [Phi-4-mini-instruct](/sdk/models/families/phi-4-mini/): part of its bounded complete baseline schedule. Pinned official BF16 checkpoint imports all 194 required artifacts into 130 compiled stages and executes original-context prefill/decode locally. On the same two-prompt float32 reference cohort, W4A4 scores 0/2, W8A8 1/2 (29.90 worst logit error), and checkpoint-bound public equalized W8A8 2/2 (9.59); five other prompts score 3/5 for both W8A8 choices. A separate two-child local prepared request completes 128 masked remote stages, with zero plaintext prompt/token-ID traffic and 1.63 MB fewer covered online bodies than matched W8A8, while increasing client bundle bytes. Tiny generated weights also pass reference parity and SDK/gateway requests. Extended-context crossing fails closed **Next:** Narrow cohorts do not establish representative generation quality or full-response compute-cap compliance; two co-located children do not establish independent-provider privacy; real-checkpoint gateway, protected execution and LongRoPE context transition (KV re-rotation) remain open.

## Candidate families

- [Mistral 7B Instruct v0.3](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3/blob/main/config.json): shared machinery exists, but this family is unchecked. Untied embeddings and Mistral checkpoint layout; this exact v0.3 config has no sliding window, while other variants need explicit window policy.
- [Llama 3.x text decoders](https://huggingface.co/docs/transformers/model_doc/llama): shared machinery exists, but this family is unchecked. Pinned public source config lowers and schedules without weights; bounded wavelength-transition scaling passes a generated tiny decoder and float32 oracle. Official Llama 3 checkpoint import, tokenizer, generation quality and deployment remain unvalidated; linear, YaRN and other scaling modes still fail closed.

## Selection and next gate

This contract is selected through source lowering and compiler admission, not by a stand-alone component. **No public Python API is exposed for selecting this operator independently.** Use the [model workflow](/sdk/models/) to inspect a source's supported scope.
