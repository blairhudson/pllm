Semantic operator/representation: `rotary_embedding`.

**Current implementation scope:** Only the Qwen3.5 text-only replicated-position, interleaved-section, partial-head float32 profile is scheduled and matched against upstream Torch at checked positions. Independent image/video axes and multimodal requests fail closed; real-checkpoint parity and protected rotary remain unchecked.

A second generated-tiny test completes prepared SDK and gateway requests with two local children, masked stage traffic and zero plaintext prompt/token-ID bytes sent.
