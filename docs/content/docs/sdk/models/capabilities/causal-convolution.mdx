Finite-window convolution state and update.

Semantic operator/representation: `causal_convolution`.

**Current implementation scope:** A bounded float32 client-side reference matches PyTorch across zero-initialized prefill and retained-state decode. The compiler admits paired convolution operators, an exact local checkpoint weight shape, and a matching prefill-to-decode state handoff. Generated tiny checkpoint execution passes local prefill/decode parity; no provider-protected or real-checkpoint claim follows.

## Python SDK example

```python
import numpy as np
from pllm.state import BoundedDepthwiseCausalConvolution

kernel = BoundedDepthwiseCausalConvolution(np.ones((2, 4), dtype=np.float32))
initial = kernel.initial_state()
prefill, retained = kernel.evaluate(
    np.ones((1, 2, 2), dtype=np.float32), initial, mode="prefill"
)
decode, _ = kernel.evaluate(
    np.ones((1, 1, 2), dtype=np.float32), retained, mode="decode"
)
assert prefill.shape == (1, 2, 2) and decode.shape == (1, 1, 2)

from pllm.state import CausalConvolutionState
from pllm.components import ModelCapabilityUnavailable

try:
    CausalConvolutionState()
except ModelCapabilityUnavailable as exc:
    assert exc.identity == "pllm/planned-model-capability/causal-convolution/v1"
else:
    raise AssertionError("missing capability must remain unavailable")
```
