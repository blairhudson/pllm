Model-neutral expert selection, private dispatch and aggregation.

This variant needs a complete model-neutral IR/numeric contract.

## Checked decoder configurations

No checked source adapter currently requires this capability.

## Candidate families

- [Qwen3 MoE](https://huggingface.co/Qwen/Qwen3-30B-A3B-Instruct-2507/blob/main/config.json): required executable variant missing. Routed/shared experts, expert selection, protected state, distribution and checkpoint import.
- [gpt-oss 20B](https://huggingface.co/openai/gpt-oss-20b/blob/main/config.json): required executable variant missing. Alternating sliding/full attention, MoE routing, YaRN, MXFP4 weight representation and checkpoint binding.
- [DeepSeek-V3 family](https://huggingface.co/deepseek-ai/DeepSeek-V3/blob/main/config.json): required executable variant missing. Multi-head latent attention, routed/shared experts, YaRN, FP8 import and complete protected/quality coverage.

## Selection and next gate

The following **importable, non-executable** classes reserve missing reusable contracts. They are excluded from component discovery, Experiment selection, search and provider registration:

- [`pllm.passes.SparseExpertRouting`](/sdk/reference/python/pllm/passes/#sparseexpertrouting) (`pllm/planned-model-capability/expert-routing/v1`): Lower typed expert selection and dispatch with bounded routing, exact checkpoint binding, and protected execution coverage..
