---
title: "Check compiler coverage"
description: "Separate primitive availability from executable whole-model operator coverage."
---

`ModelPlan.coverage(composition)` returns a native coverage report for a
specific composition and bounded semantic graph. Explicit missing operators
and incomplete protected component composition must remain failures, not
silent plaintext fallback. A complete semantic graph does not establish
checkpoint import, protected execution, quality, or deployment support.
See [inference choices](/sdk/inference/) for combinations that currently
resolve and [status](/sdk/reference/status/) for execution evidence.

## Python SDK example

```python
from pllm import Model, lower_model
from pllm.profiles import MaskedLinearCpu

config = {
    "model_type": "qwen2", "hidden_size": 64, "intermediate_size": 192,
    "num_hidden_layers": 2, "num_attention_heads": 4,
    "num_key_value_heads": 2, "vocab_size": 256,
    "max_position_embeddings": 128, "hidden_act": "silu",
    "rms_norm_eps": 1e-6, "rope_theta": 10000.0,
    "tie_word_embeddings": True,
}
plan = lower_model(config, batch=1, max_input_tokens=16, max_new_tokens=4)
report = plan.coverage(MaskedLinearCpu(Model.tiny()))
assert isinstance(report.complete, bool)
assert report.to_dict()["schema_version"] == "pllm.decoder_coverage_report.v2"
```

The tiny model choice supplies a component composition for inspection only.
For actual inference, use a supported [Experiment](/sdk/experiments/) and
[`pllm gateway --local`](/cli/reference/gateway/).

API: [`DecoderCoverageReport`](/sdk/reference/python/pllm/models/#objects-and-signatures)
