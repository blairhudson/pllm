---
title: "Inspect a model plan"
description: "Read immutable operator shapes, state transitions, and prefill/decode identity."
---

A `ModelPlan` records prefill and decode operations and typed persistent
state. `to_dict()` makes a mutable inspection copy; the plan itself keeps
canonical bytes and a content digest. Check operator provenance and shapes
before assuming a method composes with a model. The
[Learn walkthrough](/learn/inspect-a-plan/) shows the CLI alternative.

## Python SDK example

```python
from pllm import lower_model

config = {
    "model_type": "qwen2", "hidden_size": 64, "intermediate_size": 192,
    "num_hidden_layers": 2, "num_attention_heads": 4,
    "num_key_value_heads": 2, "vocab_size": 256,
    "max_position_embeddings": 128, "hidden_act": "silu",
    "rms_norm_eps": 1e-6, "rope_theta": 10000.0,
    "tie_word_embeddings": True,
}
plan = lower_model(config, batch=1, max_input_tokens=16, max_new_tokens=4)
operations = {op["id"]: op for op in plan.prefill["operations"]}
assert operations["layer.0.silu"]["operator"] == "silu"
assert len(plan.digest) == 64
```

Inspect [coverage](/sdk/plans/coverage/) before selecting a runtime. A
semantic graph and digest are not loaded weights or protected execution.
For a runnable request, follow [Qwen2 inference](/sdk/inference/masked-linear/).

API: [`ModelPlan`](/sdk/reference/python/pllm/models/#objects-and-signatures)
