---
title: "Transform a model plan"
description: "Apply one typed capability pass and preserve bounded transformation lineage."
---

`ModelPlan.apply(component)` produces a new immutable plan; it does not mutate
the original. [`KvCacheEviction`](/sdk/components/passes/kv-cache-eviction/)
is a model-neutral structural adaptation of MPCache ideas. Its state shapes
and selection operations are explicit. A successful transform is **not** a
claim that the prepared inference runtime supports transformed cache
execution. Apply it to dense Qwen2/Qwen3 plans only when its state contract
accepts them.

## Python SDK example

```python
from pllm import KvCacheEviction, lower_model

config = {
    "model_type": "qwen2", "hidden_size": 64, "intermediate_size": 192,
    "num_hidden_layers": 2, "num_attention_heads": 4,
    "num_key_value_heads": 2, "vocab_size": 256,
    "max_position_embeddings": 128, "hidden_act": "silu",
    "rms_norm_eps": 1e-6, "rope_theta": 10000.0,
    "tie_word_embeddings": True,
}
base = lower_model(config, batch=1, max_input_tokens=16, max_new_tokens=4)
transformed = base.apply(KvCacheEviction())
assert transformed.digest != base.digest
assert transformed.to_dict()["transformations"][-1]["component"] == "pllm/kv-cache-eviction"
```

To run inference today, use the **untransformed** plan through a supported
[Experiment](/sdk/experiments/) and [gateway](/sdk/run/gateway/).
The original [MPCache paper](/research/papers/mpcache/) is provenance, not
an executable dependency.

API: [`KvCacheEviction`](/sdk/reference/python/pllm/passes/#objects-and-signatures)
