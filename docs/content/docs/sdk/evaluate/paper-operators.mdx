---
title: "Benchmark paper operators"
description: "Measure installed, bounded research operators with paper citations, typed costs and explicit coverage."
---

`pllm.metrics.benchmark_operator` measures nonlinear components using their
ordinary immutable configuration. `pllm.nonlinear.MaskedWireGatedMultiplyQ12`
selects the installed Rust SIGMA-derived SiLU × up block. High cost and imperfect approximation remain
visible results. The operator runner uses a trusted local dealer/client and two
party-local evaluators in one process. The masked-wire component also has an
explicit experimental two-worker decoder binding described below.

## Python SDK example

```python
from pllm.metrics import benchmark_operator, replay_operator_benchmark, OperatorBenchmarkReport
from pllm.nonlinear import MaskedWireGatedMultiplyQ12

method = MaskedWireGatedMultiplyQ12()
report = benchmark_operator(method, lanes=64, samples=3)
assert isinstance(report, OperatorBenchmarkReport)
assert report.quality.exact_integer_outputs == 192
assert report.resources.combined_raw_key_payload_bytes == 82_592
assert report.resources.peer_frame_bytes == 6_020

# Save report.to_json() wherever you keep benchmark evidence.
replay = replay_operator_benchmark(report.configuration)
assert replay.configuration_digest == report.configuration_digest
```

Method configuration uses `ComponentRef`, `describe()`, `to_spec()`, discovery
and `with_params()`, like other SDK components. Lanes and sample counts belong
to the benchmark, not the method. `Pipeline` and `Experiment` documents can
retain these component specifications. `MaskedWireGatedMultiplyQ12` can execute
through the CPU two-offset decoder; `SharedRescale` remains an operator helper.

Each sample gets fresh OS-random one-use material. Python receives aggregate
reports; the native call releases the interpreter lock and retires both parties
on completion or error. The default public fixture includes signed boundaries,
floor-division cases and residual-table tails. Allowed limits are 1–256 lanes and
1–16 samples. The protocol preflights a 64 MiB allocation-estimate ceiling before
issuance. This is not a measurement of process peak memory.

The [standalone Python example](https://github.com/blairhudson/pllm/blob/main/examples/benchmarks/masked_wire.py)
runs against an installed wheel without Cargo or checkout imports. It accepts
`--lanes`, `--samples` and an optional `--output` path, refusing to overwrite an
existing report.

## Supply your own bounded data

```python
from pllm.metrics import benchmark_operator
from pllm.nonlinear import MaskedWireGatedMultiplyQ12

q24 = 1 << 24
custom = benchmark_operator(
    MaskedWireGatedMultiplyQ12(), lanes=4, samples=2,
    inputs={
        "gate_q24": [-q24, -1, 0, q24],
        "up_q24": [q24, q24, -q24, -q24],
    },
)
assert custom.quality.exact_integer_outputs == 8
```

Inputs are signed **Q24 integers**: gate in `[-48,48]`, up in `[-128,128]`.
Floating-point inputs and out-of-domain values reject before issuance. The
profile uses floor shifts to Q12, an effective 19-bit gate, a 1,024-entry residual
table and a 40-bit multiplication ring. It returns a Q12 gated value.

An independent Python integer oracle checks every output; disagreement aborts the
benchmark. The report separately measures approximation error against Python
float64 `SiLU(gate) × up` on the same supplied values. Exact integer parity does
not imply exact SiLU, checkpoint quality or representative generation quality.
The fixed profile previously matched 10/12 prefill and 34/36 same-token decode
selections in the retained Qwen diagnostic.

Reports omit input/output values and their hashes, and retain aggregate errors
derived from the inputs. Configuration replay uses the public fixture by default;
custom-input replay requires supplying your inputs again.

## Read the costs

`OperatorBenchmarkReport` retains immutable `OperatorBenchmarkResources`,
`OperatorBenchmarkQuality`, `OperatorBenchmarkSample` and `OperatorCitation`
records. JSON includes configuration, numeric-contract, native-source and SDK-source
digests, package/environment identity and paper source hashes.

For 64 lanes, one sample has:

| Category | Scope | Bytes |
| --- | --- | ---: |
| Raw evaluator keys | Both parties; 41,296 each | 82,592 |
| Peer frames | Both directions; all eleven phases, including frame headers | 6,020 |
| Public residual table | Per party; separate storage | 8,192 |
| Client masks | Unframed 40-bit payload estimate | 960 |
| Client entry/exit | Non-resident unframed payload estimate | 1,600 |

Resource counts are **per sample**; timing records cover each fresh issuance.
`issuance_seconds`, `online_seconds` and `clear_seconds` measure local wall time.
The clear control evaluates the same fixed integer profile. Online timing includes
the trusted client's local encoding/decoding; both evaluators execute sequentially.
`native_call_process_cpu_seconds` also includes native boundary, validation and
report metadata work. Timings are not two-host latency or GPU performance.

Key payloads omit dealer metadata and eventual transport framing. Tables,
client-mask estimates and entry/exit estimates remain separate. Full physical
wire, peak RSS and whole-checkpoint quality stay null. Compare samples only under
matching numeric contract, input workload, lane geometry, implementation and
environment; the benchmark performs no automatic ranking.

## Compare complete-block fusion

The complete-block fusion option uses the same numeric profile:

```python
from pllm.metrics import benchmark_operator
from pllm.nonlinear import MaskedWireGatedMultiplyQ12

method = MaskedWireGatedMultiplyQ12()
control = benchmark_operator(method, lanes=64, samples=3)
fused = benchmark_operator(method.with_params(layout="fused"), lanes=64, samples=3)
assert fused.quality == control.quality
assert fused.resources.peer_rounds == 8
```

An eighteen-process matched CPU cohort checks 5,778 exact outputs. At 64 lanes,
fusion cuts peer frames from 6,020 to 5,552 bytes and rounds from eleven to eight,
but increases both-party keys from 82,592 to 145,984 bytes and local online time
from 7.31 to 17.51 ms. The complete operator includes lookup, masked multiplication
and final rounding; fewer rounds alone do not establish a performance improvement.
The [saved comparison](https://github.com/blairhudson/pllm/blob/main/docs/evidence/research-masked-wire-fusion-sdk.json)
retains process RSS, separate issuance/online costs and historical Qwen-shaped
projections. It measures neither distributed transport nor a complete decoder.

## Experimental decoder execution

```python
from pllm import Deployment, ExecutionBudget, Experiment, Model
from pllm.nonlinear import MaskedWireGatedMultiplyQ12
from pllm.profiles import TwoOnlineOffsetCpu

experiment = Experiment(
    name="masked-wire-tiny",
    pipeline=TwoOnlineOffsetCpu(
        Model.tiny(), nonlinear=MaskedWireGatedMultiplyQ12(layout="fused"),
    ),
    deployment=Deployment.local(root="."),
    budget=ExecutionBudget(max_input_tokens=32, max_new_tokens=2, requests=1),
)
assert Experiment.from_spec(experiment.to_spec()).pipeline == experiment.pipeline
```

The ordinary SDK client, gateway and benchmark use this Experiment. The native
compiler replaces every admitted dense float32 SiLU/multiply pair with a bound
gated region. Conversion is explicit: the trusted client floors float32 inputs
to Q24, checks public ranges and reconstructs Q12 output as float32. Other
nonlinear operators and attention remain client-local.

Each region executes in fresh chunks of at most 256 elements. The client issues
two key packets and sends each only to its authenticated worker. Workers bind
plan, composition, region, phase, tensor index and both session IDs; malformed
frames, replay and cancellation burn the pending material. The client relays
opaque peer frames, so both relay legs count as application traffic. Issuance
runs during the response and belongs to client CPU. Memory admission prices the
client's active chunk and all eight worker-session slots. Network-offer planning
does not yet price this capability and rejects it.

The opt-in `MaskedWireGatedMultiplyQ12(dispatch="overlap")` additionally issues
one prefetched chunk and sends to the two workers concurrently within each phase.
It preserves the numeric profile, key sizes, round count and one-use context.
Client chunk/frame admission grows from 70 to 140 MiB before the existing margin;
each worker still has one active chunk per session. Cancellation drains outstanding
calls and burns the unused prefetched handle. The default is `dispatch="serial"`;
the in-process operator benchmark requires that default because it does not use
this compiled transport schedule.

Generated Qwen2/Qwen3 prefill/decode tests match an independent integer oracle's
logits and KV for both layouts. Separate-process SDK and gateway requests check
the same path. A fresh twelve-prompt pinned Qwen2.5 diagnostic matches **10/12
prefill**, **36/36 same-token decode** selections and **9/12 eight-token greedy
trajectories** against the ordinary W8A8 control. Worst logit error is **3.46**;
logits and KV are not exact. The independently checked clear numeric path covers
132,145,152 gated elements. This bounded cohort is not representative quality;
complete-response costs are measured separately. Co-located roles are not
independent operators, and this engineering adaptation has no independent
cryptographic review or malicious-output verifier.

The [quality evidence](https://github.com/blairhudson/pllm/blob/main/docs/evidence/research-nonlinear-decoder-quality-qwen25.json)
retains teacher-forced and free-running measurements separately. Both layouts
share this numeric profile; the earlier 10/12 and 34/36 figures above belong to
a different historical prompt cohort.

The [replayable decoder factories](https://github.com/blairhudson/pllm/blob/main/benchmarks/research/nonlinear_decoders.py)
retain clear-SiLU, fused/unfused and exact transport-composition choices. Changed
nonlinear numerics cannot rank against the clear-SiLU control even when selected
tokens match; fused/unfused layouts retain the same numeric comparison contract.

The first five-configuration Qwen cost sweep stopped at a 3,600-second request
timeout before producing a complete comparison. Its
[failure record](https://github.com/blairhudson/pllm/blob/main/docs/evidence/research-nonlinear-decoders-qwen25-timeout.json)
retains the frozen wheel and factory hashes. No successful response-cost or
throughput ranking is available from that attempt.

## Compare fused and unfused rescaling

`pllm.nonlinear.SharedRescale` selects the independent signed truncate/reduce
plus sign-extension helper used to study FuseFSS-style mask-aware fusion.
Each lane returns a rescaled signed integer and the **original input's**
nonnegative predicate. Both layouts use the same selected comparison backend.

```python
from pllm.metrics import benchmark_operator
from pllm.nonlinear import SharedRescale

unfused = SharedRescale(bits=16, shift=7, rounding="floor", layout="unfused")
fused = unfused.with_params(layout="fused")
control, candidate = benchmark_operator(unfused), benchmark_operator(fused)
assert control.numeric_contract_digest == candidate.numeric_contract_digest
assert control.quality == candidate.quality
assert control.resources.peer_rounds == 2
assert candidate.resources.peer_rounds == 1
assert control.resources.peer_frame_bytes == 1336
assert candidate.resources.peer_frame_bytes == 668

# Negative ties, zero and signed boundaries; already encoded integers.
custom = benchmark_operator(
    fused.with_params(rounding="ties_even"), lanes=5,
    inputs={"values": [-32768, -64, -1, 0, 32767]},
)
assert custom.quality.exact_integer_outputs == 30  # 5 lanes × 2 outputs × 3 samples
```

Allowed widths are 2–32 bits, with `1 <= shift < bits`, 1–256 lanes and 1–16
fresh samples. Inputs must be signed integers within that width. Floor and
PLLM's separate `ties_even` extension carry different numeric identities.
The nonnegative predicate remains tied to the input even when rounding returns
zero. Float64 error measures only the rescaled value against unrounded division,
in output integer units; integer-oracle checks cover both outputs.

Backends are `prefix_dpf`, `compact_dcf` and `interval_dcf` (default).
The first is a quadratic prefix control; the others use the Mixed-Mode FSS
Figure 1 DCF and Section 4.1/Figure 14 universal interval construction.
These generic arithmetic comparisons have different costs and contracts from
the SIGMA Boolean-DPF gap shifts used by the masked-wire block above.

The [installed comparison example](https://github.com/blairhudson/pllm/blob/main/examples/benchmarks/shared_rescale.py)
runs all twelve rounding/backend/layout combinations. It accepts `--bits`,
`--shift`, `--lanes`, `--samples` and a fresh `--output` path. Each result uses
the same immutable report types, records every phase/direction and replays via
`replay_operator_benchmark(report.configuration)`. Numeric comparisons remain
within one rounding contract. Custom inputs must be supplied again for replay.

Historical probe-v1 report configurations also replay through this function.
Migration emits the new component configuration and SDK digests; original
measurements and their recorded identities remain historical evidence.

Input sharing and final reconstruction are inside online timing; issuance stays
separate. The 64 MiB native combined-allocation preflight still applies. Client
estimates count one transient 32-bit input share per lane and 24 bytes per lane
for hypothetical unframed input/output share delivery. The evaluators run locally;
physical wire and measured peak memory remain unknown.

## Compare Compact, Curl and LogRow activations

```python
from pllm.metrics import benchmark_operator
from pllm.nonlinear import CompactPiecewiseActivation, CurlWaveletEncodedTable
from pllm.protocols import LogRowGarbledLookup

methods = [CompactPiecewiseActivation(), LogRowGarbledLookup(), CurlWaveletEncodedTable()]
reports = [benchmark_operator(method, lanes=5, samples=1) for method in methods]
assert len({report.numeric_contract_digest for report in reports}) == 1
assert all(report.quality.exact_integer_outputs == 5 for report in reports)
compressed = benchmark_operator(methods[-1].with_params(levels=4), lanes=5, samples=1)
assert compressed.numeric_contract_digest != reports[-1].numeric_contract_digest
```

These methods share public fitting with 1–8 pieces and 257 public offline
calibration counts. Inputs are already encoded signed Q7 integers in
`[-128,128]`; pass `inputs={"values_q7": [...]}` for custom data. The
[installed comparison example](https://github.com/blairhudson/pllm/blob/main/examples/benchmarks/activations.py)
saves all five controls, including Curl levels two and four. Every result has
paper citations, exact configuration replay and independent integer checks.

Compact evaluates private selection and polynomial arithmetic; LogRow evaluates
the fitted table; Curl performs private additive-share table lookup. Curl's
compression changes both the table and the numeric digest. Exact integer parity,
uncompressed-profile agreement and float64 SiLU error appear separately.

Resource `role_names` identify the garbler-client/evaluator pair or the two Curl
workers. Compact includes active constant labels alongside its half-gate
ciphertexts. Every method charges client material/boundary estimates and public
metadata separately. Garbled methods have no serialized **evaluator-peer**
frames; their client boundary is still an explicit payload estimate.

`public_setup_seconds` measures public fitting/table work. `clear_seconds`
measures the clear table oracle; issuance and evaluation remain separate. Lanes
execute serially with fresh material and bounded live allocation: 512 MiB for
Compact's conservative wire/gate ceiling and 1 MiB for the lookup methods.
These estimates are not peak-RSS measurements. Operator reports retain unknown
physical wire, checkpoint quality and decoder coverage.

## Complete Curl Haar gated block

```python
from pllm.metrics import benchmark_operator
from pllm.nonlinear import CurlWaveletGatedMultiplyQ9

report = benchmark_operator(CurlWaveletGatedMultiplyQ9(levels=4), lanes=8, samples=1)
assert report.quality.exact_integer_outputs == 8
assert report.resources.peer_rounds == 4
parts = report.resources.key_payload_bytes_by_operation
assert sum(a + b for _, a, b in parts) == report.resources.combined_raw_key_payload_bytes
```

The [complete-block component](/sdk/components/nonlinear/curl-wavelet-gated-multiply-q9/)
accepts `gate_q18` and `up_q18` integer arrays, with gate/up bounds ±48/±128,
and returns Q9. It charges protected index reduction, up/output rescaling,
Haar lookup and a fresh product. Exact floor/ties-even rescaling replaces the
paper's probabilistic protocol; this adaptation has separate numeric and cost
identities. Levels 0–8 are supported; samples and lanes use the same bounds as
the other helpers. Float conversion and range admission stay client-local.

The [installed example](https://github.com/blairhudson/pllm/blob/main/examples/benchmarks/wavelet_gated.py)
saves levels zero, two and four. The
[complete cost report](https://github.com/blairhudson/pllm/blob/main/docs/evidence/research-wavelet-gated-cost.json)
retains all five material owners and every frame; the
[Qwen diagnostic](https://github.com/blairhudson/pllm/blob/main/docs/evidence/research-wavelet-gated-quality-qwen25.json)
separately tests same-token logits/KV and free-running generation. Neither is a
protected whole-response measurement. Independent role transport, full wire,
protected float conversion and cryptographic review remain open.

## Complete Compact polynomial block

```python
from pllm.metrics import benchmark_operator
from pllm.nonlinear import CompactGatedMultiplyQ12

report = benchmark_operator(CompactGatedMultiplyQ12(max_pieces=8, degree=3), lanes=3, samples=1)
assert report.quality.exact_integer_outputs == 3
assert report.resources.role_names == ("garbler_client", "evaluator")
```

The [complete polynomial method](/sdk/components/nonlinear/compact-gated-multiply-q12/)
accepts Q18 gate/up inputs within ±48/±128 and returns Q12. Public calibration
controls dyadic piece refinement; a fresh circuit hides selection, evaluates
the polynomial and performs signed multiplication with exact ties-even rounding.
Its numeric identity differs from both Q7 activation-only fitting and the Q9
Curl/LogRow complete blocks. The 64 MiB serial-live allocation bound, material
by operation and role, boundary-label estimates and public metadata are explicit.

The paper's annealing and accuracy-constrained parameter search are unimplemented;
this fixed-profile CPU adaptation has separate
[operator and checkpoint evidence](https://github.com/blairhudson/pllm/blob/main/docs/research/compact-product-reference.md).
It has no tensor schedule or role transport. Zero evaluator-peer frames excludes
material delivery, and float conversion remains at the trusted client.

## Secret Replication scalar/vector correlations

```python
from pllm.correlation import SecretReplicationPcf
from pllm.metrics import benchmark_operator

report = benchmark_operator(SecretReplicationPcf(), lanes=64, samples=3)
assert report.quality.exact_integer_outputs == 192
assert report.resources.expanded_correlation_bytes_per_party == (516, 516)
```

The [correlation component](/sdk/components/correlation/secret-replication-pcf/)
consumes one full-field scalar against a vector. Expanded and punctured encodings
share that numeric contract. Reports separate dealer issuance, worker expansion,
online openings, both-party raw keys and expanded storage. Restricted scalar
masks, independent elementwise inputs and ring32 substitutions are rejected by
this contract. Its [complete evidence](https://github.com/blairhudson/pllm/blob/main/docs/research/secret-replication-reference.md)
includes exact opening-leakage counterexamples. It has a local dealer and no
compiler-bound decoder consumer or authenticated role transport.

## Paper coverage

- [SIGMA](/research/papers/sigma/): public-gap floor shifts, residual SiLU and
  masked-wire composition, independently reimplemented as a bounded CPU/Q12 block.
- [Grotto](/research/papers/grotto/): suffix-parity comparisons using
  early-terminated Boolean DPFs.
- [Pika](/research/papers/pika/): Boolean-DPF lookup/sign correction, with explicit
  correction shares and full-domain local lookup.
- [FuseFSS](/research/papers/fusefss/): the rescale/sign helper and complete
  masked-wire block adapt mask-aware multi-view fusion with matched unfused controls.
- [Mixed-Mode FSS](/research/papers/fss-mixed/): compact DCF and universal interval
  backends for that rescale helper.
- [Compact](/research/papers/compact/): public density-aware Chebyshev fitting,
  private polynomial evaluation and a separate complete Q12 SiLU × up adaptation.
- [Curl](/research/papers/curl/): party-local shared lookup and public Haar compression;
  a separate complete Q9 gated adaptation adds exact protected rescaling and multiplication.
- [LogRow](/research/papers/logrow/): masked-index table lookup with the earlier
  two-row one-hot setup and complete masked-table payload.
- [Secret Replication](/research/papers/pcf-secret-replication/): two-party line
  correlations, punctured GGM keys and a bounded full-field scalar/vector consumer.

This is a component reference exposed through the SDK. The original GPU systems,
FuseFSS's general fusion compiler, protected float conversions and independent
deployment remain separate implementation work. The explicit masked-wire
two-worker decoder binding above has its own limited execution contract. Component availability and
operator benchmarking do not establish whole-model execution, serving readiness,
complete-paper reproduction or a privacy proof.
