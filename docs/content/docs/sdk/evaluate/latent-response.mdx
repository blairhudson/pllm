---
title: "Latent response cost gates"
description: "Compare complete-response online bodies, one-use keys, and private token feedback against the same prepared decoder cohort."
---

Withholding tokens until the end does **not** eliminate autoregressive
selection: each selected token must be embedded before the next decode step.
The current compiled decoder places both greedy selection and feedback at the
client. A protected latent loop would keep activation and KV shares with two
non-colluding online parties, select the next token privately, and privately
look up its embedding; neither party could learn plaintext token IDs. There is
no admitted executor for this composition.

[`LatentResponseCostProbe`](/sdk/reference/python/pllm/metrics/#objects-and-signatures)
checks that compiler boundary before comparing two research-only approaches:

| Pinned Qwen2.5 W8A8, 39 input tokens | 8 output tokens | 32 output tokens |
| --- | ---: | ---: |
| Prepared, measured warm all-link bodies | 116.84 MB | 178.97 MB |
| Prepared, measured online bodies | 73.83 MB | 113.55 MB |
| Client attention / remote MLP, projected narrow *online only* | 6.92 MB | 10.54 MB |
| Its projected one-use keys, **both parties** | 167.03 MB | 254.18 MB |
| Fully resident, two distinct masked hidden openings *before attention* | 11.87 MB | 18.06 MB |
| Existing MPC argmax's **optimistic** peer-opening reference for required feedback | 578.57 MB | 2,562.25 MB |

The narrow MLP cut assumes packed u24 input and u32 output. It still needs
protected down projection, exact rescaling, Q7 range admission, and keys much
smaller than the current reference. The resident estimate excludes attention
arithmetic, normalization, output selection, and transport. The argmax number
is specific to an optimistic migration of the existing 17-bit authenticated
field reference, **not a lower bound on all selection protocols**. That
reference opens the selected index to the client; the bounded point-FSS
comparison supports only ten input bits, not this 151,936-token private
embedding lookup. An unknown future token cannot have a token-specific lookup
key issued ahead of the session.

Both measured runs used the pinned public checkpoint, the exact same default
39-token prompt and model-body fingerprint, one warmup, one warm measured
request, and request-sized preparation. The per-invocation prompt hashes are
deliberately salted; the fixed public token cohort has its own digest. See the
[locked response evidence](https://github.com/blairhudson/pllm/blob/main/docs/evidence/latent-response-network-qwen25-2026-09-28.json).
Counts are covered serialized bodies; full HTTP/TLS wire, independent
operators, generation quality, and matched full-response compute remain open.
Downloading public model weights to the client once does not amortize **fresh
one-use** nonlinear keys across responses.
The [small HE-to-shares experiment](/sdk/evaluate/he-quadratic-share/) measures
an actual encrypted quadratic island and checks its per-token byte floor.

## Python SDK example

```python
from pllm import Model, lower_model
from pllm.metrics import LatentResponseCostProbe
from pllm.profiles import MaskedLinearCpu

configuration = {
    "model_type": "qwen2", "hidden_size": 8, "intermediate_size": 16,
    "num_hidden_layers": 1, "num_attention_heads": 2,
    "num_key_value_heads": 1, "vocab_size": 32,
    "max_position_embeddings": 32, "hidden_act": "silu",
    "rms_norm_eps": 1e-6, "rope_theta": 10000.0,
    "tie_word_embeddings": True,
}
plan = lower_model(configuration, batch=1, max_input_tokens=2, max_new_tokens=8)
composition = MaskedLinearCpu(Model("org/bounded-source"))
report = LatentResponseCostProbe(
    maximum_online_all_link_body_bytes=10_000_000,
    maximum_total_all_link_body_bytes=20_000_000,
    maximum_material_bytes_per_party=256 << 20,
).run(plan, composition, response_new_tokens=8)
assert report["remote_mlp_cut"]["minimum_online_input_output_body_bytes"] == 504
assert report["protected_feedback_steps_before_final_client_selection"] == 7
assert report["whole_response_executable"] is False
```

API: [`LatentResponseCostProbe`](/sdk/reference/python/pllm/metrics/#objects-and-signatures).
