Five methods extend the [combined stack](/sdk/evaluate/combinations/).
Generated-prefix qualification is a new cache option; state transfer is an
explicit trusted-client operation. Three native research probes remain outside
Pipeline execution.

| Method | Checked result | Remaining gate |
| --- | --- | --- |
| Generated-prefix qualification | 24 Qwen states match all logits/KV; covered conversation total 402.05 → 366.63 MB | Longer fixed horizons, client peak memory, full wire |
| Cross-configuration state transfer | Exact suffix replay across delivery and attention-placement changes | Automatic cache migration and matched switching costs |
| Masked worker aggregation | Exact integers; client downloads halve | Peer bytes replace the saving; client CPU rises about 5.3× |
| Token-local projection memo | 27/58 hits; exact checked logits/KV | At most 0.41% body saving; 2.06 MB added weight/snapshot storage |
| Progressive head precision | 16/16 exact greedy certificates at each precision | Six-bit private refinement projects 40.8 worker CPU seconds; no public capacity bound |

The conversation gain is **8.8% over an already optimized control**. No tenfold
result follows: the common 241.72 MB first-response cost already exceeds this
cohort's 40.20 MB tenfold budget. Counts cover application bodies, not full wire.

## Python SDK example

```python
import numpy as np
from pllm import Model
from pllm.metrics import (
    GeneratedStateReuseProbe, StateCompatibilityProbe, MaskedAggregationProbe,
    TokenLocalProjectionProbe, ProgressiveHeadProbe,
)
from pllm.profiles import MaskedLinearCpu
from pllm.quantization import SymmetricPerRow
from pllm.state import ClientPrefixReuse

pipeline = MaskedLinearCpu(
    Model.tiny(),
    quantization=SymmetricPerRow(causal_reduction="prefix_f32"),
    cache=ClientPrefixReuse(
        max_bytes=8 << 20, fixed_input_tokens=128, generated_prefixes=True,
    ),
)
assert pipeline.components["cache"].params["generated_prefixes"] is True
assert GeneratedStateReuseProbe(steps=4).steps == 4
assert isinstance(StateCompatibilityProbe(), StateCompatibilityProbe)
assert TokenLocalProjectionProbe(cache_bytes=1 << 20).cache_bytes == 1 << 20
assert ProgressiveHeadProbe(prefix_bits=6).prefix_bits == 6

# Public fixture: native codec screen, not a live role topology.
relay = MaskedAggregationProbe(repetitions=1).run(
    np.array([[14, 91]], dtype=np.uint32),
    np.array([[10, 23]], dtype=np.uint32),
    bytes([16, 16]),
)
assert relay["exact_integer_parity"]
assert not relay["all_link_gate_passed"]
```

API: [metrics](/sdk/reference/python/pllm/metrics/#objects-and-signatures),
[`ClientPrefixReuse`](/sdk/reference/python/pllm/state/#clientprefixreuse),
and [`CompiledRuntimeModel`](/sdk/reference/python/pllm/runtime/).
`transfer_snapshot(snapshot, target)` compares validated numeric contracts,
preserves verifier lineage, checks native bounds and returns an independent
client-local snapshot. It rejects response-owned snapshots. The seal is trusted
client-local provenance, not authentication of caller-mutated arrays.

Generated qualification requires the [canonical full-KV numeric mode](/sdk/components/quantization/symmetric-per-row/).
Pending tokens stay excluded; cancellation and `store=False` retain no generated
prefix. Existing acknowledgements and one-use rules remain enforced.

Rust owns arithmetic, masks, codecs, memo kernels and certificates; Python owns
SDK options, orchestration, budgets and independent controls. Head certificates
cover greedy selection with a fully resident oracle, not private retrieval.
