---
title: "Resident-share gate research"
description: "Bound one-use nonlinear key distribution and both peer directions before attempting a share-resident decoder."
---

`pllm.metrics.ResidentQuadraticGateCostProbe` inspects a complete semantic
decoder schedule and counts a **one-use, two-party** candidate at each gated
MLP operation. Its local numeric reference makes one masked 24-bit hidden
opening, then evaluates private coefficients for the unrounded quadratic Q7
SiLU×up numerator, `(256g + g²)u`, without opening the wider gate or up
tensors. The dealer gives each party its **own** source-mask share and five
coefficient shares per output; its test-only implementation binds the session,
graph, channel, profile, and operation and burns material on use or failure.

For a Qwen2.5-0.5B-shaped **39-input/one-output** schedule, the MLP-gate-only
projection is 5,031,936 online all-link body bytes and 70,806,528 bytes of
dealer material **per party**. This fits selected gate-only limits of 6 MB
online and 256 MiB per party. It does **not** establish protected model
execution: the Q7 quadratic has a restricted range, its polynomial numerator
has scale 65,536 rather than the decoder's two-stage rounded Q7 output, and
the 24-bit source range has not been validated for pinned model weights.

Use `run_two_source_layer_bound()` to charge a second, distinct semantic
source for attention query projection. That raises the optimistic opening-only
estimate to **10,063,872 online bytes**, or **419,328 per layer**, before
attention arithmetic, protected softmax, RMSNorm, truncation, transport
framing or output shares. It fails the 6 MB whole-decoder / 250 kB per-layer
target; no decoder-scale material is issued. The dense Q3/Q7 lookup
alternatives are even more expensive in offline keys. These are explicit
method bounds, **not** lower bounds on every possible two-party protocol.
The [locked gate evidence](https://github.com/blairhudson/pllm/blob/main/docs/evidence/resident-quadratic-layer-gate-2026-09-28.json)
records four candidate methods, exact configuration and schedule digests,
and all admitted/blocked claims. See [research topology candidates](/learn/topologies/research-candidates/)
for the trust and whole-decoder gates.
For generated sequences, the [latent response cost gate](/sdk/evaluate/latent-response/)
also charges autoregressive private selection and one-use keys over the full response.

## Python SDK example

```python
from pllm import Model, lower_model
from pllm.metrics import ResidentQuadraticGateCostProbe
from pllm.profiles import MaskedLinearCpu

configuration = {
    "model_type": "qwen2", "hidden_size": 8, "intermediate_size": 16,
    "num_hidden_layers": 1, "num_attention_heads": 2,
    "num_key_value_heads": 1, "vocab_size": 32,
    "max_position_embeddings": 32, "hidden_act": "silu",
    "rms_norm_eps": 1e-6, "rope_theta": 10000.0,
    "tie_word_embeddings": True,
}
plan = lower_model(configuration, batch=1, max_input_tokens=2, max_new_tokens=1)
composition = MaskedLinearCpu(Model("org/bounded-source"))
probe = ResidentQuadraticGateCostProbe(
    maximum_material_bytes_per_party=256 << 20,
    maximum_online_all_link_body_bytes=6_000_000,
    maximum_online_body_bytes_per_layer=250_000,
)
gate = probe.run(plan, composition, response_new_tokens=1)
layer = probe.run_two_source_layer_bound(plan, composition, response_new_tokens=1)
assert gate["layers"][0]["hidden_elements"] == 2 * 8
assert layer["layers"][0]["independent_attention_source_elements"] == 2 * 8
assert layer["decoder_material_issuance_admitted"] is False
```

API: [`ResidentQuadraticGateCostProbe`](/sdk/reference/python/pllm/metrics/#objects-and-signatures).
