PLLM ships one Python package backed by Rust. The public API separates model
planning from live runtime state so you can inspect and reproduce a plan without
including credentials, masks, sessions, or model weights.

## Choose a workflow

Start with [inference options](/sdk/inference/) to choose weight ownership and
protection. Each option has a complete `Experiment` example and an exact gateway
invocation. The [comparison](/sdk/inference/compare/) covers role and trust
differences. Then use [configuration](/sdk/configuration/) to record intent,
[model guides](/sdk/models/families/) to check architecture support, and
[plan inspection](/sdk/plans/) to distinguish semantic coverage from execution.

To select or extend an individual method, use [components](/sdk/components/)
and the [component inventory](/sdk/reference/components/). A component can be
importable without being accepted by a profile or usable in a whole-model runtime.
[Running PLLM](/sdk/run/) covers client and provider roles;
[evaluation](/sdk/evaluate/) covers benchmark cohorts, search, evidence, and
assurance. For exact constructor signatures, use the
[Python API reference](/sdk/reference/python/pllm/).

The base package supports configuration, planning, and inspection. Before running
a local-gateway example, choose the required runtime variant from the
[installation guide](/learn/installation/).

## Install the package

Add the `pllm.run` distribution from PyPI to a uv project. It provides the
`pllm` import package:

```bash
uv add pllm.run
```

## Python SDK example

Create a normal Python module containing a supported `Experiment`:

```python
from pllm import Deployment, ExecutionBudget, Experiment, Model
from pllm.profiles import MaskedLinearCpu

experiment = Experiment(
    name="private-qwen",
    pipeline=MaskedLinearCpu(Model("Qwen/Qwen2.5-0.5B-Instruct")),
    deployment=Deployment.local(root="local://private-qwen"),
    budget=ExecutionBudget(requests=1, max_input_tokens=64, max_new_tokens=8),
)
resolved = experiment.resolve()
assert resolved.client_runtime == "masked_transformer_v1"
assert resolved.requires_preparation
```

Serve that exact object through the trusted local gateway:

```bash
pllm gateway --local \
  --experiment experiment.py:experiment \
  --trust-python \
  --api-key local
```

Then use the [OpenAI Python SDK guide](/learn/integrations/openai-python/) or any
other supported client integration to make the request. The component-family
guides use the same experiment shape while changing the component under study.

API: [Python SDK objects and signatures](/sdk/reference/python/pllm/#objects-and-signatures)

## Compose research methods

Apply a compatible component to a model plan to create a new plan with a record
of the transformation. Compatibility with a semantic plan does not by itself
establish compiler, runtime, privacy, quality, or deployment support.

## Run supported workflows

Runtime APIs cover specific public-weight and confidential-weight workflows.
Support depends on the model, protocol, operator set, deployment, and threat
model. Check [current support](/sdk/reference/status/) before choosing a path.
