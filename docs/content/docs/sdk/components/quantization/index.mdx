---
title: "Quantization"
description: "Choose masked-linear numeric precision as a versioned Experiment component."
---

[`SymmetricPerRow`](/sdk/components/quantization/symmetric-per-row/) selects
weight and activation precision. [Public per-channel equalized W8A8](/sdk/components/quantization/public-per-channel-equalized/)
is a second, explicit numeric choice: it uses fixed public offline calibration
bound to the checkpoint, transforms each body weight stage and adjusts its
activation on the client before masked inference. The choice lives in
`Pipeline.components["quantization"]`; the equalization profile digest also
binds the stage/body identity. Omitting the slot preserves old pipeline
identities and uses the existing eight-bit local-role default.

`SymmetricPerRow` offers four or eight bits for each dimension, independently,
in the masked-linear baseline or opt-in verified counterpart. Equalized W8A8
works with public baseline client-owned or prepared stages. Other protocols,
missing calibration artifacts, and unknown numeric implementations fail closed.
Selection binds the same settings across client, preparation and inference; a
conflicting explicit role override is rejected.

This is an execution choice, not a quality score. See
[reference agreement](/sdk/evaluate/metrics/reference-agreement/) and compare measurements on the
same pinned checkpoint and token workload before favoring a setting.

## Python SDK example

```python
from pllm import Deployment, ExecutionBudget, Experiment, Model
from pllm.profiles import MaskedLinearCpu
from pllm.quantization import SymmetricPerRow

model = Model.tiny("qwen2")
w4 = MaskedLinearCpu(model, quantization=SymmetricPerRow(weight_bits=4, activation_bits=4))
w8 = MaskedLinearCpu(model, quantization=SymmetricPerRow(weight_bits=8, activation_bits=8))
experiment = Experiment(
    name="w4a4",
    pipeline=w4,
    deployment=Deployment.local(root="local://numeric-options"),
    budget=ExecutionBudget(requests=1, max_input_tokens=8, max_new_tokens=2),
)
assert experiment.resolve().composition_digest == w4.digest()
assert w4.digest() != w8.digest()
```

API: [`pllm.quantization`](/sdk/reference/python/pllm/quantization/#objects-and-signatures).
