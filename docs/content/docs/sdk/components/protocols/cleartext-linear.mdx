---
title: "Cleartext linear control"
description: "Place clear linear operators on the trusted client for client-only inference."
---

[`CleartextLinear`](/sdk/reference/python/pllm/protocols/#cleartextlinear)
(`pllm/cleartext-linear`) declares a linear operator whose executor sees its
inputs. It is accepted only with the complete `ClientOnlyCpu` topology: every
linear kernel and the public model weights stay on the trusted client. That
Experiment runs through the ordinary gateway and benchmark driver. The bare
descriptor cannot authorize private inference or enable this placement by
itself; cleartext client execution is not evidence of protected provider
activations. This is PLLM-specific infrastructure, not a paper implementation.

## Python SDK example

```python
from pllm.protocols import CleartextLinear

control = CleartextLinear()
assert control.component == "pllm/cleartext-linear"
assert control.describe().role_eligibility == ("client", "inference")
```

Use it through a complete [client-only Experiment](/sdk/topologies/options/),
or choose a [masked-linear experiment](/sdk/inference/masked-linear/) when
public body weights remain with the prepared provider roles.

API: [`CleartextLinear`](/sdk/reference/python/pllm/protocols/#objects-and-signatures)
