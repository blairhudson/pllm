[`Cpu`](/sdk/components/kernels/cpu/) supports the shipped provider and
client-owned compositions. The optional
[`AppleMetal`](/sdk/components/kernels/apple-metal/) runs client-owned or provider-owned public
integer prefill on Apple Silicon with a declared CPU decode fallback.
`threads` is an explicit positive CPU bound, not evidence
of a speedup. Native matrix execution, scalar/SIMD dispatch, conversions, and
network protocol costs are measured separately under the
[benchmark guide](/sdk/evaluate/benchmark/). Changing kernels does not alter
the model adapter, privacy contract, or verified component selection.

## Python SDK example

```python
from pllm.kernels import Cpu

backend = Cpu(threads=2)
assert backend.component == "pllm/cpu"
assert backend.params["threads"] == 2
```

For a complete local execution, apply this backend in the
[CPU option guide](/sdk/components/kernels/cpu/) and run its `Experiment` via
`pllm gateway --local --experiment experiment.py:experiment --trust-python`.

API: [Kernel backend](/sdk/reference/python/pllm/kernels/#objects-and-signatures)
