---
title: "Chunked independent lanes"
description: "Bound streamed one-use nonlinear tensors without a resident unbounded program."
---

[`ChunkedIndependentLanesProtectedTensorSchedule`](/sdk/reference/python/pllm/schedulers/#chunkedindependentlanesprotectedtensorschedule)
(`pllm/chunked-independent-lanes/v1`) accepts an explicit limit from five to
four million elements. It authenticates independent lane order and a bounded
spool for larger research tensors. A large admitted limit does not mean the
model is compiled, that live preparation is supported, or that a protected
whole decoder can be served. This scheduler is PLLM-specific infrastructure.

## Python SDK example

```python
from pllm.nonlinear import R03CrtGatedMultiplyQ7
from pllm.schedulers import ChunkedIndependentLanesProtectedTensorSchedule

method = R03CrtGatedMultiplyQ7()
schedule = ChunkedIndependentLanesProtectedTensorSchedule(max_elements=64)
assert method.component == "pllm/r03-crt/v1"
assert schedule.params["max_elements"] == 64
```

This declares a bounded native-region pairing, not a full private model
`Experiment`. Use [masked-linear inference](/sdk/inference/masked-linear/)
and its gateway command for supported end-to-end execution.

API: [`ChunkedIndependentLanesProtectedTensorSchedule`](/sdk/reference/python/pllm/schedulers/#objects-and-signatures)
