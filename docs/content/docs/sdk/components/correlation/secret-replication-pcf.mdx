title: "Secret-replication PCF"

---

`pllm.correlation.SecretReplicationPcf` is an experimental, operator-only
correlation source (`pllm/secret-replication-pcf/v1`). It independently implements
the two-party line construction and punctured GGM keys from
[Secret Replication](/research/papers/pcf-secret-replication/), then consumes each
correlation once in modular scalar/vector multiplication.

## Python SDK example

```python
from pllm.correlation import SecretReplicationPcf
from pllm.metrics import benchmark_operator, replay_operator_benchmark

method = SecretReplicationPcf(field=257, encoding="punctured")
report = benchmark_operator(method, lanes=64, samples=3)
assert report.quality.exact_integer_outputs == 192
assert report.resources.raw_key_payload_bytes_per_party == (164, 164)

replayed = replay_operator_benchmark(report.configuration)
assert replayed.resources == report.resources
```

## Contract and options

| Option | Values | Meaning |
| --- | --- | --- |
| `field` | `2`, `17`, `257` | Complete prime field for scalar, vector and result |
| `encoding` | `"expanded"`, `"punctured"` | Expanded leaf-key control or GGM seed compression |

One scalar applies to the complete vector. Caller-owned inputs use
`inputs={"scalar": [scalar], "vector": values}`, with canonical nonnegative field
integers and exactly `lanes` vector entries. Omitting inputs uses a public fixture.
The report stores neither inputs nor outputs. Benchmark geometry is separate:
1–256 lanes and 1–16 fresh samples. Native admission prices a combined 16 MiB
allocation bound before issuance; this is not measured RSS.

## Costs and ownership

The in-process dealer creates two distinct party-local states. Each owns only
its correlation share; fresh context and issuance bind each exchange. Completion,
malformed frames, replay and cancellation burn material. Native execution releases
the interpreter lock; no reusable secret handle reaches Python.

Reports distinguish dealer issuance, worker correlation expansion and local online
exchange. Both-party keys, expanded correlations, PRF work, directional peer frames
and client-boundary estimates remain separate. At field 257 and 64 lanes,
puncturing reduces combined raw keys from 16,424 to 328 bytes, while expanded
correlations stay 1,032 bytes and peer frames stay 676 bytes. This does not
establish lower whole-client memory or full-wire cost.

Restricted scalar masks cannot hide arbitrary field inputs in this consumer.
Reusing its scalar mask for independent elementwise inputs reveals differences;
the method is therefore not a drop-in ring32 Beaver-triple or FSS-key compressor.
Large scalar domains increase per-coordinate PRF work. The local dealer,
unauthenticated reference frames and unreviewed AES adaptation do not establish
distributed setup, independent providers or cryptographic review.

The component supports discovery, immutable replacement and serialization.
Decoder Experiment resolution remains unavailable. See the
[installed benchmark](https://github.com/blairhudson/pllm/blob/main/examples/benchmarks/secret_replication.py)
and [source, counterexamples and costs](https://github.com/blairhudson/pllm/blob/main/docs/research/secret-replication-reference.md).
