[`ArithmeticGarblingSiluQ7`](/sdk/components/nonlinear/arithmetic-garbling-silu-q7/)
protects a bounded unary SiLU region. For gated multiplication,
[`BinaryTableGatedMultiplyQ7`](/sdk/components/nonlinear/binary-table/) and
[`R03CrtGatedMultiplyQ7`](/sdk/components/nonlinear/r03-crt/) implement
alternative bounded Q7 reference constructions. Method identity and
[scheduler](/sdk/components/schedulers/) are distinct capability contracts.
[`MaskedWireGatedMultiplyQ12`](/sdk/components/nonlinear/masked-wire-gated-multiply-q12/)
selects the SIGMA-derived residual SiLU × up block;
[`SharedRescale`](/sdk/components/nonlinear/shared-rescale/) selects signed
floor/ties-even rescaling with fused/unfused comparison backends. Both use the
same immutable component contracts and a separate
[operator benchmark function](/sdk/evaluate/paper-operators/).
[`CompactPiecewiseActivation`](/sdk/components/nonlinear/compact-piecewise-activation/),
[`CurlWaveletEncodedTable`](/sdk/components/nonlinear/curl-wavelet-encoded-table/)
and [LogRow fitted-table lookup](/sdk/components/protocols/logrow-reference/)
benchmark one shared publicly calibrated Q7 profile, with different ownership
and compression contracts. The [numeric fitter](/sdk/components/nonlinear/compact-q7-reference/)
remains separately inspectable.
The masked-wire Q12 method has an experimental two-worker decoder binding;
the bounded Q7 methods have operator execution only. Consult
[current support](/sdk/reference/status/) and
[research evidence](/research/evidence/) before interpreting region timings.

## Python SDK example

```python
from pllm.nonlinear import BinaryTableGatedMultiplyQ7, R03CrtGatedMultiplyQ7

reference = BinaryTableGatedMultiplyQ7()
compact = R03CrtGatedMultiplyQ7()
assert reference.component == "pllm/binary-table/v1"
assert compact.component == "pllm/r03-crt/v1"
```

These Q7 objects are bounded research selectors, not `Experiment` inference slots.
For end-to-end private inference use the supported
[masked-linear experiment](/sdk/inference/masked-linear/) and its
`pllm gateway --local --experiment experiment.py:experiment --trust-python`
command. There is no protected-Q7 whole-decoder gateway path today.
