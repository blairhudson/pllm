title: "Network planning"
description: "Select immutable experiments against explicit offers, then admit execution separately."

Network planning takes a model-neutral lowered model, explicit candidate
`Experiment` objects, a `PlanningPolicy`, and an immutable `NetworkSnapshot`.
[`pllm.compiler.plan`](/sdk/reference/python/pllm/compiler/#objects-and-signatures)
enumerates bounded assignments; native validation owns role legality, declared
operator separation, and aggregate capacity. Planning does not load model weights,
probe hosts, reserve capacity, or authorize a live session.

Start with [network records and discovery](/sdk/deployment/network/), then
[execution leases](/sdk/deployment/execution/). The same selected experiment can
run through the SDK, gateway, and ordinary benchmark route.

## Python SDK example

Run from the repository root. This is an offline geometry fixture, not a source
lock or inference example. Field names and capabilities follow the executable
[`network_planning.py` fixture](https://github.com/blairhudson/pllm/blob/main/examples/benchmarks/network_planning.py).
Offers get fresh timestamps on every run.

```python
import time

from pllm import Deployment, ExecutionBudget, Experiment, Model, lower_model
from pllm.compiler import plan
from pllm.deployment import NetworkSnapshot, NetworkSpec, PartyOffer
from pllm.plan import PlanningResult
from pllm.profiles import ClientOnlyCpu, MaskedLinearCpu, TwoOnlineOffsetCpu
from pllm.search import PlanningPolicy, PlanningRequest

config = {
    "model_type": "qwen2", "hidden_size": 8, "intermediate_size": 16,
    "num_hidden_layers": 1, "num_attention_heads": 2,
    "num_key_value_heads": 1, "vocab_size": 32,
    "max_position_embeddings": 256, "hidden_act": "silu",
    "rms_norm_eps": 1e-6, "rope_theta": 10000.0,
    "tie_word_embeddings": True,
}
budget = ExecutionBudget(requests=1, max_input_tokens=5, max_new_tokens=2)
model_plan = lower_model(config, batch=1, max_input_tokens=5, max_new_tokens=2)
candidates = tuple(
    Experiment(profile.__name__, profile(Model.tiny()),
               Deployment.local(root="local://network-planning"), budget)
    for profile in (ClientOnlyCpu, MaskedLinearCpu, TwoOnlineOffsetCpu)
)
now = time.time_ns() // 1_000_000
capabilities = (
    "trusted_client", "trusted_preparation",
    "masked_linear_provider", "public_linear_provider",
)
offers = tuple(
    PartyOffer(
        party, party, str(index + 1) * 64, now + 600_000,
        ("trusted_client",) if party == "client" else capabilities[1:],
        256 << 20, 64 << 20, 4, 0,
        (model_plan.to_dict()["config_digest"],), ("*",),
    )
    for index, party in enumerate(("client", "worker-a", "worker-b"))
)
snapshot = NetworkSnapshot(
    "local-demo", offers, (), "generated-fixture", now, now + 600_000
)
network = NetworkSpec("local-demo", snapshot)
request = PlanningRequest(
    model_plan, candidates,
    PlanningPolicy("client", now, 8, 1000,
                   ("total_arithmetic_body_bytes", "client_weight_bytes"),
                   minimum_remote_mac_fraction=0.5,
                   max_observation_age_ms=600_000),
)
decision = plan(request, snapshot=snapshot)
assert decision.status == "feasible" and decision.exhaustive
assert decision.experiment.name in {"MaskedLinearCpu", "TwoOnlineOffsetCpu"}
assert PlanningResult.from_spec(decision.to_spec()).digest == decision.digest
assert network.snapshot.digest == decision.snapshot.digest
```

API: [`PlanningRequest` and `PlanningPolicy`](/sdk/reference/python/pllm/search/#objects-and-signatures)

## Policy and evidence boundaries

Candidates must share exact model source, numeric contract, and budget. Model-plan
prefill/decode bounds must match that budget. Objectives are ordered explicitly;
unknown required costs fail closed rather than becoming zero. Arithmetic body
estimates omit HTTP/TLS framing and checkpoint distribution. CPU, peak memory,
full-wire bytes, and setup time remain unknown without admitted evidence; declared
`CandidateCostEvidence` is an estimate, not a measurement certificate.

`minimum_remote_mac_fraction` names either `body_linear` or `all_linear` as its
denominator. Token lookup is excluded. Logical matrix work is not credited twice
because two offset workers evaluate it. The planner weights body stages by
`max_input_tokens + max_new_tokens - 1` and the vocabulary head by
`max_new_tokens`; per-row artifact diagnostics are a different denominator.

`ArtifactCostEvidence.from_manifest(...)` binds actual public object sizes and
declared resident keys to a source-locked candidate. Supply one record per
candidate in `PlanningRequest.artifact_evidence`; use
`PlanningPolicy(reuse_horizon=...)` to price a bounded repeated workload.
`horizon_accounted_body_bytes` charges missing public objects once, authenticated
manifests per workload, and fresh corrections and online bodies every time.
Resident declarations remain estimates; execution verifies objects and repairs
corrupt cache entries. Private KV and one-use rows never enter this public list.

## Immutable decisions

[`PlanningResult`](/sdk/reference/python/pllm/plan/#objects-and-signatures) contains
request/snapshot digests, selected experiment and native placement, costs,
alternatives, rejections, and coverage. JSON import replays native validation and
scoring; editing a cost or placement is rejected. Canonical bytes and public
digests contain no capacity credentials or one-use material.

`feasible` means a winner was found; inspect `exhaustive` before claiming a complete
search. Exhaustive no-winner results are `infeasible`; bounded searches with no
winner are `inconclusive`. Incomplete feasible results require explicit
`allow_incomplete_execution=True` before execution. Revalidation checks current
expiry, selected host epoch, and capacity; a saved decision is not a reservation.
