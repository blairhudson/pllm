## Source contribution

Arithmetic garbling provides free additions and specialized gadgets, with a stated symmetric-primitive security model.

## PLLM perspective

Create a reviewed arithmetic-label core with modulus-specific offsets, permitted constant operations, projection and mixed-modulus gadgets. Keep offsets opaque.

Affine-label arithmetic exists in archived references; no proof-equivalent native port has been established.

PLLM has related clean-room reference primitives only. They are not a paper reproduction, reviewed protected runtime, or complete-model result.

The source's boundary remains binding: Functionality alone does not validate affine-label correlations or an arbitrary hash replacement. Reject unsupported non-unit constants or lower them through justified gadgets.
