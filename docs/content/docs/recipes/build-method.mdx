description: "Turn a published method into a versioned component and a recorded plan change."
---

A new reimplementation follows distinct identities:

```text
source record -> method semantics -> clean-room reference -> fidelity result
-> semantic component implementation -> typed composition/recipe
-> assurance + matched benchmark -> publication eligibility
```

Composition records exact source, method, component, implementation, model, numeric graph, roles, privacy contract, workload, and plan identities. Changed inputs create new lineage; evidence never transfers by name similarity.
