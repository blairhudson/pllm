---
title: "Inspect role topology"
description: "Display role channels and local operator-separation diagnostics."
---

From a repository root checkout with PLLM installed, inspect the same
Experiment used by the [SDK guide](/sdk/topologies/):

```bash
pllm topology inspect examples/pllm.yaml --format json
```

The result includes the configuration and composition digests, a versioned
role-graph digest, offline and online channels, and placement diagnostics. A
`Deployment.local(...)` experiment reports Preparation and Inference on the
same operator; this is not an independent-provider privacy result. The command
resolves installed components but starts no provider, loads no checkpoint, and
performs no attestation.

The current prepared public topology is also a component identity:
`pllm/one-online-provider-offline-preparation/v1`. An Experiment may include
that identity in its `topology` slot to bind the same runtime graph explicitly;
the [SDK example](/sdk/topologies/options/) shows the immutable Pipeline
construction. Unlisted topologies remain unavailable for execution.

Inspect a versioned role-placement declaration without using it for serving:

```bash
uv run --frozen pllm topology inspect examples/prepared-topology.yaml --role-deployment examples/prepared-role-deployment.json --format json
```

The report keeps the actual Experiment's local co-location warning separate
from the declaration's operator labels. `declared_separation_violations: []`
means labels and literal origins are consistent, **not** verified operator
independence. TEE policies report unverified attestation and cannot activate a
new provider protocol.

`--reference client-only` or `--reference two-online-offset` inspects the
corresponding bounded research graph instead of the installed graph. These
graphs cannot be served or benchmarked as `Experiment` topology choices.

Inspect the checked-in explicit selection and validate benchmark admission
without loading weights or starting services:

```bash
pllm topology inspect examples/prepared-topology.yaml --format json
pllm --dry-run benchmark run --experiment examples/prepared-topology.yaml --max-output-tokens 1 --repetitions 1 --format json
```

Use `pllm topology inspect path.py:experiment --trust-python` only for an
explicitly trusted Python target. Unknown or incomplete compositions fail
instead of presenting a made-up executable graph. See
[Learn: Topologies](/learn/topologies/) for assumptions and
[current serving](/cli/private-inference/) for runnable commands.
