PLLM installs one Python package with a Maturin-built extension:

```text
pyproject.toml                 Python project and Maturin configuration
Cargo.toml                    Rust workspace and shared version
python/pllm/                  SDK, CLI, roles, protocol, dashboard
crates/pllm-core/             Python-independent integer core
crates/pllm-python/           PyO3 binding as pllm._native
tests/                        Python/protocol/integration tests
benchmarks/                   Current native and live measurement tools
docs/                         Static Fumadocs application
paper/, research/             Canonical paper and historical evidence
```

Application code imports public objects from `pllm`; `pllm.runtime` is internal.
The docs, paper, and research tree are not installed in the wheel except packaged
dashboard assets under `python/pllm/dashboard`.

## Public-path setup

```bash
uv sync --locked
pllm build
```

Public seeded preparation does not require TenSEAL. Add `--extra he` only for HE
tests or optional confidential/BFV paths; add `--extra sdk` for installed OpenAI
SDK tests.

## Rust changes

```bash
cargo test --locked -p pllm-core
cargo clippy --locked --workspace --all-targets -- -D clippy::correctness
uv run maturin develop --release
PLLM_REQUIRE_RUST=1 uv run pytest -m rust
```

Matrices own immutable weight snapshots. Native calls release the Python
interpreter lock but copy bytes across the binding. Include conversion and retained
source-matrix storage in benchmarks.

## Python and protocol changes

```bash
uv run ruff check python/pllm scripts tests
uv run pytest
uv run python scripts/check_repository.py
```

For public-path changes, exercise inventory authorization/READY state, one-way
correction push, row reservation/burn, all three ring widths, compact long prefill,
persistent decode, local boundary matrices, and the dashboard telemetry boundary.

The NumPy backend is an explicit correctness reference:

```bash
PLLM_KERNEL_BACKEND=python uv run pytest -m 'not rust and not he and not sdk'
```

It cannot satisfy native release evidence.

## Distribution

```bash
uv build
uv run python scripts/check_distributions.py dist
uv run twine check --strict dist/*
```

Wheel jobs install outside the checkout and require the Rust backend. Cargo,
Python, citation, and tag versions are checked together by `scripts/release.py`.

## Documentation

```bash
cd docs
npm ci
npm run check:content
npm test
```

For a full framework validation, additionally run `npm run typecheck` and
`npm run build`. Those commands generate Fumadocs state and static exports; avoid
them when a task explicitly excludes generated outputs. Paper/evidence generation
is separate and should run only for intentional research or release changes.
