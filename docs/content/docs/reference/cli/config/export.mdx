---
title: "pllm config export"
description: "Exact pllm config export help from the installed PLLM CLI."
---

## Example

```bash
pllm config export examples/pllm.yaml --output experiment.json
```

## Options

```text
usage: pllm config export [-h] [--format {human,json,jsonl}] [--quiet]
                          [--no-color] [--no-input] [--dry-run] [--factory]
                          [--trust-python] --output PATH [--force]
                          TARGET

positional arguments:
  TARGET                experiment .json/.yaml or explicit
                        path.py:object/module:object

options:
  -h, --help            show this help message and exit
  --format {human,json,jsonl}
                        result format (default: human)
  --quiet               suppress non-error diagnostics
  --no-color            disable colored output
  --no-input            fail instead of prompting
  --dry-run             report work without persistent writes or service
                        startup
  --factory             call explicit zero-argument Python factory
  --trust-python        approve execution of the explicit local Python target
  --output PATH         new output .json/.yaml path
  --force               replace an existing output file
```
