## Options

```text
usage: pllm components [-h] [--format {human,json,jsonl}] [--quiet]
                       [--no-color] [--no-input] [--dry-run]
                       COMMAND ...

positional arguments:
  COMMAND
    list                list built-in component descriptors
    show                show one component descriptor

options:
  -h, --help            show this help message and exit
  --format {human,json,jsonl}
                        result format (default: human)
  --quiet               suppress non-error diagnostics
  --no-color            disable colored output
  --no-input            fail instead of prompting
  --dry-run             report work without persistent writes or service
                        startup
```
