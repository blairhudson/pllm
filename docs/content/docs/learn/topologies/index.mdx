---
title: "Topologies"
description: "Where private inference work runs, how roles connect, and what each arrangement assumes."
---

A **topology** names roles and directed channels between them. A protocol says
what each role computes; a deployment says which operator and machine runs each
role. Changing a URL does not change a privacy protocol or give two processes
independent operators.

Four executable CPU compositions share the compiled decoder: client-only,
one online provider plus offline Preparation, two online additive-offset
workers, and Freivalds-verified offline Preparation plus one online provider.
`pllm topology inspect` displays each resolved Experiment's role/channel
graph. `Deployment.local(...)` co-locates service roles under one operator;
their separation requirements are **not** satisfied by a local run.

The selectable client-only option executes the full model on the client:
online provider bytes are zero, while checkpoint distribution, weight
storage, memory and client computation belong in the comparison.

[network and compute comparison](/learn/topologies/network-and-compute/),
[research topology candidates](/learn/topologies/research-candidates/), and
[TEE conventions](/learn/topologies/trusted-execution/). Use the
