    response = client.responses.create(

02 / UNDER THE INTERFACE

Private, one operation at a time.

Homomorphic work happens before the activation is needed. Every mask is used once.

Prepare without revealing the mask.

The client encrypts fresh random masks. The provider transforms them with the model matrix, and the client decrypts the matching output masks.

Enc(r) → Enc(Wr)
The secret key stays on your side.

Turn the prompt into private model state.

The client tokenises locally and connects masked matrix operations with attention, recurrence, and nonlinear operations. Every prompt row consumes fresh preparation.

private activation x → x + r mod p
The provider receives the masked value.

Recover the result. Keep the text.

The client subtracts the prepared mask, updates private state, and samples a token. It emits normal Responses events only after the result is reconstructed locally.

W(x + r) − Wr = Wx mod p
Decoded output returns to your application.
