One request is more than one matrix.

The latency of private inference includes preparing fresh masks, moving them between machines, processing the prompt, generating tokens, and discarding unused work. Measuring only a warm server kernel hides much of that cost.

This paper completes a coefficient GEMM preparation path, follows a trained small model through isolated client and provider processes, and accounts for the resources of a Qwen3.5-27B text graph. It also defines the API and deployment boundary needed to turn the experiment into a usable service.

What changed in this edition: a source mapped runtime description, installation and deployment contracts, an explicit separation between the default server and the newer preparation study, and one shared benchmark record for the paper and website.
