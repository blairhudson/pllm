Research record / 8-10 September 2026

Protocol history, with its dead ends intact.

  4. 10 SEP 2026
    DESIGN GATE
    Rejected shortcut

    Reuse prepared correction rows

    Reusing an input mask would expose the modular difference between two private activations, so greater throughput cannot come from replaying inventory. The design instead reserves each row once and burns unused rows after cancellation, failure, or early completion. Reconsideration requires a different reviewed protocol whose proof permits reuse; caching or implementation tuning cannot relax this boundary.

  5. 10 SEP 2026

    Current runtime

    Offline prepared inventory

    Preparation moved fully before chat. Batched stage roots now generate one-time masks, corrections, and tickets; inference seals only a completely acknowledged inventory as READY. Online requests contact inference alone. Reservations burn on early end or failure, and memory-only inventory expires on restart or idle timeout, making refill and waste explicit costs rather than hidden retries.

    Prepared execution and KV allocation

    Follow-up work retained unused inventory across completed chats, refilling only when the next reservation exceeded the remainder. Client KV storage changed from repeated concatenation to geometric capacity growth, grouped-query attention stopped materializing repeated keys and values, and final-token generation skipped an unused decode step.     Current runtime

    Compact long-context transport

    Prefill now packs a ticket vector and masked row matrix into one bounded stage message, executes one matrix batch, and returns one compact response; decode keeps its single-row form. Server accounting still counts logical rows, validates context and allocation limits, and consumes every ticket. Tests cover long prompts and failure boundaries, while physical wide-area and production-scale measurements remain missing.

Reading rule

Historical BFV and seeded-relay numbers answer whether specific experiments ran. Current inventory tests answer whether protocol invariants hold in covered fixtures. Local acceptance observations do not substitute for matched repeated cold/warm studies, an independent cryptographic review, or a production non-collusion assessment.
