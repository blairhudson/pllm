  --model-id MODEL_ID   public model ID, one per model

                        weights; this declaration is required
  --client-trust, --client-security {honest,guarded,untrusted}
                        honest trusts the published client; guarded adds
                        budgets and rate limits; untrusted requires the
                        authenticated shares compiler and currently fails
                        closed
  --activation-protection, --linear-protocol {automatic,precomputed-masks,guarded-blinded-masks,blinded-masks,encrypted-activations,authenticated-shares}
                        advanced choice for protecting each remote model stage
