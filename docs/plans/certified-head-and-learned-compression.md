# Certified head replies and checkpoint-specific learned compression

## Decision

Continue the completed [four-track screen](../research/sota-breakthrough-reference.md)
with two bounded vertical slices. The original measurements and failed helper
remain immutable. Source-specific head coding targets an incremental exact byte
improvement; learned compression has a separate quality and execution identity.

Three Sol 6.1 workers own non-overlapping implementation areas:

| Area | Ownership | First acceptance gate |
| --- | --- | --- |
| Certified head replies | Existing SDK/native boundary contracts, focused tests and `private-boundary-row-codec-sdk.md` | Explicit trusted source artifact, independently checked worker bounds, exact full-vector reconstruction and generated SDK lifecycle parity |
| Matched head comparison | New `private_boundary_row_codec` benchmark modules, scripts, tests and reference | Ordinary fresh-process response targets, raw-counter reconciliation and complete-client resource accounting |
| Stronger checkpoint helper | New `checkpoint_compression` research modules, scripts, tests and reference | Frozen fresh public evaluation, useful full-input baseline, complete small-model inventory and executable training/evaluation path |

The parent owns integration, independent review, builds, installation, real
checkpoint work, publication of evidence and aggregate documentation. Lightweight
correctness tests may run independently; model values, sustained fitting, native
builds and performance cohorts run serially with existing resource guards.

## Recorded outcome

- **Certified heads:** installed native/compiler, generated decoder and supervised
  SDK/gateway checks pass. A six-client generated-source response cohort preserves
  83,352 exact logit/KV values and complete state/output commitments, with zero
  observed swap growth, reconciled actual frames and receipt-backed replay.
  The first pinned Qwen publication rejects host admission before tensor loading.
  After memory is freed, a fresh publication matches all independently scanned
  row widths and records zero observed swap growth. The six-client 150+8 screen
  preserves 52,561,920 checked values, with 8.31% smaller head payload, 0.17% less
  total TCP traffic and 2.41% faster decode, but 1.18% slower full requests.
  Largest complete-client peak is 221.66 MiB; median/paired RSS changes do not
  establish a memory improvement. Receipt replay and independent audit pass.
  The first 150+64 attempt is memory-admission blocked after one control and stays
  excluded. A separate six-client retry preserves 486,555,648 checked values with
  zero swap growth, 0.91% less TCP traffic and 0.87% faster decode. Full requests
  are effectively unchanged; five-owner cold CPU rises 2.86%. Largest candidate
  peak is 217.83 MiB, with mixed paired RSS changes. These separate initial
  screens retain independent-confirmation gates.
- **Learned helper:** the frozen Qwen full-input admission gate rejects after 30
  valid QA cases: 13 correct, 17 errors. Even perfect remaining QA reaches only
  47/64 (73.4375%), below the required 75%. The 19,776-parameter helper's label
  generation, fitting and held-out evaluation remain blocked. A retained
  pre-child memory rejection contributes no quality observation.
- **Evidence:** original failures and accepted smoke remain separate. See the
  [head benchmark](../research/private-boundary-row-codec-benchmark.md) and
  [compression reference](../research/checkpoint-compression-reference.md).
  Neither track establishes a new serving SOTA or a client-memory-tier win.

## Exact head gate

The incumbent uses parallel dispatch and uniform residues. A candidate may change
only the explicitly bound head reply layout and its required public certificate;
source, numeric behavior, kernel, body ownership and role graph remain matched.
Original defaults keep their identity.

A thin client must authenticate the actual certificate bytes against independently
approved publisher/source commitments. A worker's own claimed digest is not that
approval. Each boundary worker verifies the certificate against its immutable
weights. The client receives no vocabulary matrix. Source, scale, quantizer,
geometry, layout and implementation mismatches reject before one-use sessions.
Bounded import, decoding, native allocation and cancellation remain mandatory.

Generated Qwen2/Qwen3/Llama checks must preserve complete integer/float32 head
outputs, decoder logits, active KV, selections and RNG. Negative controls cover
substitution, malformed layouts, stale sources, replay and failure retirement.

After those gates, compare three balanced fresh clients per arm at **150+8**
and, separately, **150+64** requested tokens under native shared 100/40 Mbps caps.
Natural EOS remains authoritative. Each workload retains its own cohort, source
and build locks. The worker includes SDK, supervisor, dashboard, relay and state
audit; its largest replicate peak determines observed Low/Medium eligibility.
The existing SDK's two-arm order is AB/BA/BA; record and audit that exact order
under one private cohort salt rather than claiming strict AB/BA/AB alternation.

Report all seven serving objectives plus full-request and complete-lifecycle time
and aggregate CPU. Reconcile actual directed bodies and TCP streams. Charge
certificate creation and publication separately; distinguish local reads,
pre-positioned artifacts, measured delivery and unknown source-cold costs. The
historical 8.31% head-payload opportunity and 7.88 ms bandwidth-floor difference
are not measured SDK gains. A winning screen still needs independent confirmation.

## Learned-compression gate

Prepare and lock new public article/context-disjoint training, validation and
held-out cohorts before fitting. Exclude original pilot examples; retain copying,
rare strings, order and longer-context controls alongside useful QA. Freeze
prompt templates, metrics, quality margins, fallback rule and hyperparameters.
Several hundred evaluation cases are the next quality target, rather than four
questions. Unknown teacher pretraining exposure stays explicit.

First run the original full-input target on a separately declared baseline gate.
An incomplete or weak baseline does not authorize expensive fitting or a useful
compression claim. The model must be meaningfully stronger than the 264-parameter
ranker, with fewer than one billion **total runtime parameters**, including every
frozen backbone, embedding and output component. Per-checkpoint learned artifacts
share model-neutral tooling; other checkpoints remain untrained until measured.
This ceiling applies to the complete learned helper, not the separately owned
frozen public target. Target parameters, loading, execution and fallback costs
remain explicitly counted; a hidden helper backbone cannot be excluded.

Compare original full input, zero-training/lexical compression, learned compression
and fresh fallback-inclusive execution. Target adaptation additionally requires
full-adapted and compressed-adapted controls. Gold answers cannot decide fallback.
The original target remains provider-owned in the proposed private serving path;
local-clear teacher costs and process peaks do not qualify that client.

Useful held-out quality, value over lexical selection, and at least 20% lower
**measured first-request all-link traffic** within the selected client-memory tier
are subsequent serving targets. Helper delivery, local computation, tokenizer,
original context retained for retry and every failed attempt remain charged.
Arithmetic projections and synthetic mechanics cannot satisfy those targets.

Manifests bind code dependencies, source and data before execution. Bounded
per-item progress survives failure/timeout without qualifying unfinished models.
Only completed independent gates may advance; old holdouts and failed attempts
are neither retuned nor silently replaced.
